========================================
  METRIC DEFINITIONS
========================================

ACCURACY: Overall correctness of predictions
  Formula: (TP + TN) / (TP + TN + FP + FN)

PRECISION: When model predicts a match, how often is it correct?
  Formula: TP / (TP + FP)
  High precision = fewer false alarms

RECALL (Sensitivity): Of all actual matches, how many did we find?
  Formula: TP / (TP + FN)
  High recall = fewer missed matches

F1 SCORE: Harmonic mean of precision and recall
  Formula: 2 * (Precision * Recall) / (Precision + Recall)
  Balances precision and recall

TP = True Positives (correct match)
FP = False Positives (incorrect match)
FN = False Negatives (missed match)
TN = True Negatives (correct rejection)
